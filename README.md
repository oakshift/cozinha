# Cozinha

Despensa, lista de compras, ementa da semana e receitas da família, partilhadas entre dois telemóveis.

- App: https://oakshift.github.io/cozinha/
- Os dados ficam num repositório privado à parte (`cozinha-dados`), lido e escrito pela app com um token do GitHub guardado só no navegador. Sem token próprio, usa o do Descomplica (mesmo site), se tiver acesso a esse repositório.
- Cada alteração é uma operação guardada neste navegador e aplicada à cópia mais recente no GitHub, para duas pessoas poderem mexer ao mesmo tempo, mesmo sem rede.
